🏀 Basketball File Upload

Uma interface web altamente interativa, moderna e acessível que transforma a experiência de envio de arquivos em um jogo de arremesso de basquete baseado em física 2D em tempo real.

🏀 Demonstração & Conceito

O Basketball File Upload une a gestão funcional de arquivos com elementos de gamificação. Os usuários podem fazer o upload de documentos de três maneiras intuitivas:

Arremesso Manual: Arrastando o cartão do arquivo para trás e soltando para arremessar na cesta.

Drag & Drop Direto: Soltando arquivos em qualquer ponto da quadra ou na caixa de marcação.

Seleção Tradicional: Utilizando o botão "Procurar Arquivos" ou acionando a funcionalidade "Arremesso Automático".

✨ Destaques & Funcionalidades

⚙️ Engine Física 2D (60 FPS): Cálculo em tempo real de gravidade, impulso elástico, parabólica de trajetória, colisões nos aros e efeito de pontuação (Swish).

🎯 Mira Preditiva: Linha de vetor e pontos de projeção que indicam se a bola/arquivo acertará o alvo antes da soltura.

🌓 Sistema de Temas (Dark/Light): Alternância instantânea de modo claro e escuro com persistência no localStorage.

📊 Progresso Reativo: Indicador visual em tempo real do status de upload de cada arquivo com feedback percentual.

⚡ Desempenho Otimizado: Animações executadas exclusivamente via aceleração de hardware (GPU com transform e opacity).
